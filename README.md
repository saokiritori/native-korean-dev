# native-korean-dev

Claude Code 가 한국어로 답할 때 자연스럽고 정확한 한국어를 쓰게 하는 output style 입니다. 

## 개발 배경

### "여기서 로직이 **갈립니다**."
### "이 변경으로 **회귀**가 발생할 수 있습니다."
### "두 판정은 서로 **직교**합니다."
### "**읽는 사람** 잘못이 아닙니다."
### "규칙 **다섯**입니다."

도대체 뭐가 자꾸 갈리는 것일까요...뭐가 자꾸 회귀할까요... 직교하고..회귀하고..갈리고... 그리고 쓸데없이 숫자는 왜 이리 집착하는 것일까요. '읽는 사람'이라고 풀어서 설명해준 것 같아 기특하지만, '독자'라는 정확한 한국어 표현이 있습니다.

☠️☠️☠️ 자세히 읽으면 이해가 가는데, 너무너무너무 답답합니다. ☠️☠️☠️

작성자도 이런 문장을 읽으며 자신의 독해력을 의심했고, 이제 AI 와 일하려면 AI 말투를 해독하는 능력을 따로 길러야 하는지 고민했습니다. 

이 output style 은 그 어휘 선택을 바로잡습니다.

> Claude Code 는 한국어로 설명할 때 영어 문장 구조를 그대로 옮기고, 개발 현장에서 통용되는 용어를 (독자의 이해를 위해?) 모호한 일상어로 대체하며, 수학 용어를 비유로 끌어 쓰는 경향이 있습니다.

| 적용 전 | 적용 후 |
|---|---|
| 여기서 로직이 갈립니다 | 조건에 따라 처리 경로가 분기됩니다 |
| 이 변경으로 회귀가 발생할 수 있습니다 | 이 변경으로 기존에 동작하던 기능이 다시 고장 날 수 있습니다 |
| 이 설정은 사용자에 의해 변경될 수 있습니다 | 사용자가 이 설정을 변경할 수 있습니다 |
| 좋은 질문입니다! 지금부터 차근차근 설명해 드리겠습니다 | (도입 문장 없이 바로 대답 진행) |

기존에 공개된 스킬·프롬프트 저장소를 둘러보니, 저의 구조에 빠르고 간결히 적용하기에 불편하다고 느꼈습니다.
그래서 이 저장소에는 `styles/native-korean-dev.md` 파일 하나만 있고, 앞으로도 쓸데없이 파일을 늘리거나 복잡한 규칙을 추가하지 않고 이 한 파일만 간결하게 유지할 계획입니다. 자신이 필요하지 않다고 생각하는 조항들은 과감히 삭제해주세요. 

## 사용 방법

```sh
mkdir -p ~/.claude/output-styles
curl -fsSL https://raw.githubusercontent.com/saokiritori/native-korean-dev/main/styles/native-korean-dev.md \
  -o ~/.claude/output-styles/native-korean-dev.md
```

`~/.claude/settings.json` 에 아래 설정을 넣습니다. Claude Code 안에서 `/config` 를 열어 Output style 항목에서 `native-korean-dev` 를 선택해도 됩니다.

```json
{
  "outputStyle": "native-korean-dev"
}
```

새 세션을 열어야 적용됩니다. 특정 프로젝트에서만 쓰려면 그 프로젝트의 `.claude/settings.local.json` 에 같은 키를 넣습니다.
